Example

To add a new page:

  1. Copy this file into pages/ and change the title and content.
  2. Add it to the PAGES list in scripts/update_header.py, e.g. "pages/new.html".
  3. Add a menu link in scripts/header.html, e.g. <a href="/pages/new.html">New</a>.
  4. Run python scripts/update_header.py to copy the shared head and header into all pages.
